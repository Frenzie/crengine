Class-bucketed selector test suite

Tests LVStyleSheet::buildSel0Index() / apply() in lvstsheet.cpp. These bucket the _selectors[0] chain by leading class so a node only visits buckets it can match. The cascade (specificity, source order, pseudo-elements) must behave exactly as before.

1. Class buckets stay separate

each class matches its own color; look-alikes must not.
expected: green is green-bordered, red red, blue blue; redd, blue2, greenish get no border.

2. Source order wins across buckets

.pink and .violet have equal specificity but live in different buckets.
expected: violet text (later source rule wins) regardless of class order.
pink violet
violet pink (still violet)

3. Specificity beats bucket order

#s3 .shallow (0,2,0) is defined before .deep (0,1,0); both match.
expected: green border.
deep shallow

4. Class + pseudo-element selectors

regression: a class-leading ::before/ ::after must still apply (it must not be bucketed by class, since pseudo-element nodes carry no class).
expected: note shows "[NOTE] ... [end]"; warn shows "!!"; note warn shows "!! ... [end]" (the later .warn::before overrides content, as there is one ::before box).

first child of .probe — must be italic (#s5 .probe :first-child).

second child of .probe — must NOT be italic.

attribute, element-name, and universal leading rules always apply.

multi-a multi-b reach both buckets; .only must not leak to class-less nodes.
